# Zyroofficial Mod v0.3.0 (Minecraft 26.2, Fabric)

Keys (change in Options > Controls): Right Shift = menu, O = auction, M = money stats, J = move HUDs,
H = show/hide HUD, comma = win streak +1, period = reset streak.

Counting: starter rules "X paid you $5B" (received) and "You paid X $1M" (sent). If your server words
payments differently, open Menu > General > Recent messages, click Make Rule on the real line.
Lines with a $ that match no rule are kept for you to see in Recent messages.

Auction: Menu > General > Auction (or O). Type the item, a timer (30s, 5m, 1h30m, 2d), optional min bid, press Start.
Players pay you; the HUD board shows who paid the most; when time ends the winner and amount are shown and posted.

Build: push to GitHub; Actions builds the jar (Artifacts > jar). Local: ./gradlew build, jar in build/libs.
